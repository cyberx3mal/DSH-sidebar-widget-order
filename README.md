# Порядок виджетов в сайдбаре DSH

Русский | [English](README.en.md)

Плагин для DeepSeek Harness: меняет порядок виджетов в нижней части левой панели
(`sidebar.footer.action`) стрелками ↑ и ↓. Стрелки находятся только на странице
настроек — на самих виджетах их нет.

## Установка

1. Скопируй папку плагина в удобное место.
2. Открой DSH → **Настройки → Плагины → Добавить плагин** и выбери эту папку.
   Если пользуешься CLI: `dsh plugin --profile desktop add "<путь к папке>"`
   (замени `desktop` на имя своего профиля).
3. Включи плагин в списке и обнови страницу (Ctrl+R).

## Как пользоваться

1. Открой **Настройки** (внизу слева).
2. Выбери раздел **«Порядок виджетов»**.
3. Двигай виджеты стрелками ↑ и ↓ — порядок применяется сразу.

Порядок сохраняется в браузере под ключом `dsh.sidebar.footer.order.v1` и остаётся
после перезапуска. Он локальный: на другом компьютере настрой его заново.

## Как это работает

Страница сохраняет список id в `localStorage` и отправляет событие
`dsh/sidebar-footer-order`. Каждый виджет по событию перерегистрируется с новым
`order = (позиция + 1) × 10`. Страница не трогает компоненты, стили и DOM других
плагинов и не работает, пока настройки закрыты.

## Свой виджет

Новый виджет появляется в списке автоматически: страница читает живые записи через
`ctx.slots.entries('sidebar.footer.action')`, без захардкоженного списка. Название
берётся из `label` регистрации, иначе показывается `id`.

Чтобы виджет участвовал в порядке, он должен брать `order` из общего списка и
перерегистрироваться по событию. Готовый шаблон и правила:
[docs/ADD-WIDGET.md](docs/ADD-WIDGET.md).

## Ограничения

- Порядок хранится в браузере, а не в профиле DSH: на другом устройстве его нужно
  настроить заново.
- Если виджет выключен во время перестановки, при включении он вернётся на свой
  `order` по умолчанию, пока его снова не подвинуть.
